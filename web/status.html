Quick Start

Create a rift to your local service:

ssh -t -R 0:localhost:8080 user@{{.BaseDomain}}

This will:

  • Connect to the Rift server via SSH
  • Create a reverse tunnel from a public URL to your localhost:8080
  • Give you a unique subdomain like abc123.{{.BaseDomain}}
  • Show an interactive dashboard with real-time stats

Examples

Tunnel a web server on port 3000:

ssh -t -R 0:localhost:3000 user@{{.BaseDomain}}

Tunnel a database (TCP):

ssh -R 5432:localhost:5432 user@{{.BaseDomain}}

Features

  • 📊 Interactive TUI with real-time request monitoring
  • 📈 Live statistics (bytes, requests, connections)
